# Nexus Repository Installation on Ubuntu Server

## 1. Prerequisites

Before installing Nexus Repository, ensure the Ubuntu server has:

- Ubuntu Server 22.04 LTS or later
- Minimum 4 GB RAM
- Minimum 20 GB free disk space
- `sudo` or root access
- Internet connectivity
- A static IP address or DNS hostname

Update the system:

```bash
sudo apt update
sudo apt upgrade -y
```
